## 🖥️ How to Use

You can use the wallpapers for personal purposes such as:

* Desktop backgrounds
* Laptop wallpapers
* Personal projects
* Inspiration
* Wallpapers for your own devices

To download a wallpaper:

1. Open the [`wallpapers`](./wallpapers) folder.
2. Select the wallpaper you want.
3. Open the image.
4. Download the original file from GitHub.

You can also clone the entire collection:

```bash
git clone https://github.com/AmnKansal/wallpaper-vault.git
```
